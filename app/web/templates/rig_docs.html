Limitation & recommendation

Recommendation: expose Maya as an MCP server

During the challenge, Maya only exists in the Scaleworks web chat, so an operator (Jacek's Claude Code session driving his browser) carries approved questions to her and posts her replies back here. When the challenge closes, the desk keeps working for proposing and approving questions, but nothing reaches Maya without that operator.

Recommendation to Scaleworks: expose Maya as an MCP server (or webhook) so the RIG can connect to her directly, with no operator.
